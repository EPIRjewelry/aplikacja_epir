## Summary

Poprawki buyer po retescie PR #169 (gałąź `fix/buyer-after-169` z `main@29993b9`):

- **Indeks opcji z koszyka sesji** — `get_cart` preload + `fetchProductFactsForVariantIds` → `VariantOptionIndex` (rodzeństwo wariantów ze Storefront).
- **Zmiana wariantu** — dziedziczenie `selected_options` tylko gdy dokładnie jedna linia produktu; przy wielu — pytanie po nazwie/opcjach (nigdy `line_id`); target z `findVariantIdBySelectedOptions` / faktów; brak lub niedostępny → notice, bez zgadywania.
- **`update_cart`** — jedno full replacement (`line_items` + zachowana atrybucja); odpowiedź z pełnymi opcjami i ceną z wyniku narzędzia / indeksu.
- **Link koszyka** — po mutacji strip wszystkich `/cart/c/` z tekstu modelu + jeden nowy z bloku; bez mutacji tylko `continue_url` z `get_cart` wykonanego w tej turze (nie z sesji/historii).
- **Formularz indywidualny** — EPIR + **GZ** hardcode `https://epirbizuteria.pl/pages/zaprojektuj-swoj-model`; Kazka z `ai_profile.custom_order_url`; KB relative → origin kanału; host-kanał w strażniku.
- **`buyer.timing`** — `get_cart_ms` / `total_ms` / `tool_rounds` / `cart_mutated` (bez URL i tokenów).
- **Bez zmian:** `MAX_TOOL_ROUNDS=3`, `index.ts`, `waitMs` / BuyerTurnGate, temperatura.
